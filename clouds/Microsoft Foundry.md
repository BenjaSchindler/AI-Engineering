# Microsoft Foundry

![[assets/clouds/foundry.svg|72]]

**Qué es:** Plataforma de Azure que reúne modelos, agentes y herramientas de evaluación y gobierno para aplicaciones de IA.

**Para qué sirve:** Permite explorar modelos, organizar un proyecto y construir aplicaciones generativas con servicios del ecosistema Azure. Por ejemplo, un asistente recupera políticas mediante Azure AI Search y utiliza un modelo para redactar respuestas sobre garantías con ese contexto.

**Clave:** La documentación actual usa Microsoft Foundry; materiales anteriores pueden llamarlo Azure AI Foundry y describir proyectos o SDK de experiencias clásicas.
