# Google Cloud Observability

![[assets/clouds/cloud-observability.svg|72]]

**Qué es:** Familia de herramientas de Google Cloud para observar logs, métricas y trazas de aplicaciones.

**Para qué sirve:** Sirve para diagnosticar errores y localizar demoras mediante Cloud Logging, Cloud Monitoring y Cloud Trace. En un agente sobre Cloud Run, un identificador conecta la solicitud con las etapas de recuperación, generación y llamadas a herramientas para encontrar la dependencia lenta.

**Clave:** Las trazas explican tiempos de ejecución; la calidad de la respuesta necesita evaluación específica del contenido.
