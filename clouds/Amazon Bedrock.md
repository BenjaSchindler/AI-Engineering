# Amazon Bedrock

![[assets/clouds/bedrock.svg|72]]

**Qué es:** Servicio gestionado de AWS que ofrece acceso a modelos fundacionales de distintos proveedores para construir aplicaciones de IA generativa.

**Para qué sirve:** Permite enviar instrucciones y contexto a un modelo sin administrar sus servidores. Por ejemplo, un asistente de soporte usa una política de devoluciones como contexto y genera una propuesta de respuesta estructurada para el cliente.

**Clave:** Bedrock aporta inferencia; ejecutar un agente o recuperar documentos requiere componentes adicionales, como AgentCore y Knowledge Bases.
