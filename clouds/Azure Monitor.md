# Azure Monitor

![[assets/clouds/azure-monitor.svg|72]]

**Qué es:** Plataforma de Azure que observa aplicaciones e infraestructura mediante métricas, logs, trazas y alertas.

**Para qué sirve:** Sirve para detectar problemas operativos y relacionar solicitudes con dependencias mediante Application Insights y consultas de Log Analytics. En un agente Gen AI, la instrumentación conecta búsqueda, modelo y herramientas con la misma solicitud para localizar errores o demoras y configurar alertas.

**Clave:** Una API rápida y sin errores puede producir respuestas incorrectas; la calidad exige evaluar su contenido.
